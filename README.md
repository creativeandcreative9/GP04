# 月のクッキー工場 / Moon Cookie Factory

完成版の「雲上の月光工房」（雲塊の独立移動・パン・ズーム付き60秒動画）は [dream/README.md](dream/README.md) を参照してください。初期シンプル版のソースと見本は、このルートに残しています。

固定カメラで右から左へ流れる工場映像です。初版の無音映像を維持したまま、静かな空調音と柔らかな金属音を追加しました。汎用編集システムではなく、この1種類の映像を決定論的に生成する専用スクリプトです。外部素材・API・有料サービスは不要です。

## 音付き版（2026-10-13）

`output/moon-cookie-factory-sound.mp4` が音付き見本です。24秒、1920×1080、30 fps、AACステレオ48kHz / 192kbps。元の `moon-cookie-factory.mp4` は無音のまま保持し、映像ビットストリームをコピーしているため映像内容の変更や再圧縮はありません。

環境セットアップ後、既存の無音MP4から音付き版を再生成:

```sh
python audio.py
# 空調音と加工音は独立調整できます（単位dBFS）。
python audio.py --background-db -42 --process-db -28
```

ゼロから再生成する場合は `python render.py` → `python audio.py` の順です。空調はRMS基準、加工音は3工程を合成したバスのピーク基準です。過大な設定はエラーにし、暗黙のリミッターや自動音量補正はかけません。`air-conditioning.wav`、`process-metal.wav`、`soundtrack.wav` も書き出します。

音はすべてNumPyによるオリジナルの数式合成です。第三者録音・音楽・追加の有料サービスは使いません。空調は高域を抑えた周期的な帯域ノイズとごく小さなファン音。加工は430 / 610 / 790Hzを基音にした弱い非整数倍音で金属感を作り、約100msの柔らかな立ち上がりと約1〜1.5秒の穏やかな減衰を付けています。鋭い高域・衝撃的なアタックを抑えた設計です。

映像と音声は `timing.py` の工程時刻を共用します。各6秒サイクルの1.26秒でコーティング、1.44秒でプレス、1.62秒で型抜きが開始します。既存映像では3駅が並行稼働するので、音も近い時刻に重なります。製品が通過する順序は右からプレス→型抜き→コーティングです。

空調は24秒周期のFFT合成、金属音は前のループの余韻を先頭に折り返して加算しており、冒頭に無音フェードや残響のリセットを入れません。`audio.py` はPCMとMP4からデコードしたAACのピーク・DC成分・境界の波形差分、AACの時間位置、映像のビットストリーム一致を確認します。検証詳細は `output/audio-verification.json`、独立したラウドネス・トゥルーピーク測定は `output/audio-meter.txt` に保存します（生ログはGit対象外。今回の結果の要約は `output/audio-meter-summary.txt`）。

実際の試聴はこの環境ではできていません。波形・同期・ファイル仕様の検証済みで、睡眠時の快適さや実際の再生音量の聴覚評価は未実施です。AACやプレーヤーのループ再生処理による機器固有の隙間は保証できません。確認は `preview.html` または通常の動画プレーヤーで再生してください。

## 見本と実行方法

- `output/moon-cookie-factory.mp4`: 24秒、1920×1080、30 fps、H.264 / yuv420p、音声なし。
- `output/contact-sheet.jpg`: 実際に書き出したMP4から抽出した加工前・加工中・加工後・搬送中の6枚。
- `output/verification.json`: ffprobeとソースフレーム差分の検証結果。

Python 3.11以上、FFmpeg / ffprobe（libx264有効）、DejaVu Sansフォントが必要です。Debian/Ubuntuのセットアップ例:

```sh
sudo apt-get install ffmpeg fonts-dejavu-core python3-venv
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python render.py
```

動画再生成は上の最後の1コマンドです。出力を上書きします。CPUで処理するため数分かかります。映像のプレビューはMP4を通常の動画プレーヤーで開き、ループ再生を有効にしてください。ブラウザで確認する場合はこのフォルダで `python3 -m http.server 8000` を実行して `http://localhost:8000/preview.html` を開けます。

```sh
python render.py --still 1.8  # output/preview.png に加工途中の静止画
python render.py --verify    # 既存MP4の仕様検証とフレーム抽出のみ
```

## 工程と反復

6秒で1ピッチ（画面上160px、出力上320px）移動する間欠搬送です。最初の3.6秒は停車して加工し、後半2.4秒で滑らかに左へ移動します。位置補間と機械動作はsmoothstepで、始終速度は0です。24秒は4サイクル。製品は画面外で補充され、各製品が次のステーションへ移っても形と色を引き継ぎます。

1. 右のプレス：下降するヘッドに合わせ、生地玉が横に広がり薄くなります。
2. 中央の型抜き：ダイの下降に合わせ、丸い生地の右側を透明な切り欠きに変えて三日月を作ります。
3. 左のコーティング：ノズルの流れに合わせ、生地色が淡いクリーム色に変わります。

色・背景・照明は一定です。カメラ移動・点滅・ランダムな動きはありません。元画像からフルHDで描画し、縮小画像の拡大はしていません。

## 検証

`python render.py` は書き出し後に検証を行います。再生時間24秒、720フレーム、1920×1080、30/1 fps、映像1ストリーム・音声0をassertで確認します。時刻0と24秒のソース画像はピクセル単位で完全一致します。末尾23.9667秒と先頭との差分平均もJSONに記録します。終端フレームの重複は入れません。加えてMP4の全720フレームをデコードし、480×270に縮小した比較画像で、末尾→先頭の平均絶対差が通常の隣接フレーム差の最大値以下であることを検証します。実MP4の0.5/1.8/3.2/3.6/4.8/5.9667秒を抽出して目視確認します。

## 制約と保存

2Dの図案的なプロトタイプです。物理シミュレーション・写実的な3D表現・型抜きの余剰生地回収は未実装です。コーティングは均一な色補間で、液体物理は使用しません。搬送中も連続で加工する方式ではなく、各駅で停止する方式です。初版の無音MP4はそのまま残しています。MP4プレーヤー固有のループ時の待ち時間は映像自体では制御できません。

ソース、README、依存指定、無音・音付きの見本MP4、工程一覧画像、検証結果をGitで管理します。再生成できるWAV・個別PNG、キャッシュ、Library用ZIPバックアップはGitには含めません。独立バックアップはLibraryに保存済みです。サイト公開・YouTube投稿は行っていません。
